## 使用方式

1. 先看 [`00-骨架與紀律.md`](00-骨架與紀律.md) —— 所有範本都是這個骨架的實例
2. 照順序用 01 → 04，會把上午手寫的成果完整重做一次
3. 卡住時用 [`05-除錯回報.md`](05-除錯回報.md)
4. 完成後用 [`06-產生測試.md`](06-產生測試.md) 產生測試
