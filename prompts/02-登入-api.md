# 02 · 登入 API

對應簡報 Step 4–5、demo 的 `step-4-login-api`。這是最完整的一份範本。

---

## 完整提示詞

```
你是資深 Python 後端工程師。

目標：用 FastAPI 寫一支登入 API。

規格：
- POST /api/login
- 輸入 JSON：username、password
- 成功回 200，body 是 {"token": "隨機字串"}
- 失敗回 401，detail 是「帳號或密碼錯誤」
- 帳號不存在和密碼錯誤，都回同一個訊息
- token 用 secrets.token_hex(16) 產生，存在記憶體的 dict

限制：
- 只寫這一支 API，不要順便加別的功能
- 不要用 JWT、不要接資料庫，我還沒學
- 不要寫 try/except 包住全部
- 每段加繁體中文註解

輸出：完整的 main.py，以及測試用的 curl 指令。
```

---

## 為什麼規格裡要寫「都回同一個訊息」

這是資安慣例。如果「帳號不存在」和「密碼錯誤」回不同訊息，攻擊者就能用它確認哪些帳號真的存在，然後專攻那些帳號。

**AI 預設常常會分開回。** 這就是你需要懂、才能下對指令的地方。
