# Step 1 — 最原始的伺服器

## 跑起來

```bash
python3 main.py
```

然後用瀏覽器打開 <http://127.0.0.1:8000>

## 你應該看到

畫面上出現「我是伺服器，我聽到你了」，而終端機**不會回到提示符** —— 它還在跑。

## 這一步的重點

- 伺服器 = 一個一直在聽某個 port 的程式，不會自己結束
- `8000` 是 port，同一個 port 同時只能有一個程式在聽
- 按 `Ctrl + C` 才會停止

## 常見問題

**`Address already in use`** — 上一個伺服器還活著。回到那個終端機按 `Ctrl + C`。
