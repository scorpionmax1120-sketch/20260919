# 指令小抄

> macOS / Linux 用 `python3`、`pip3`；Windows 用 `python`、`pip`。

## 虛擬環境

```bash
python3 -m venv .venv                 # 建立
source .venv/bin/activate             # 啟動（macOS / Linux）
.venv\Scripts\Activate.ps1            # 啟動（Windows PowerShell）
deactivate                            # 離開
```

成功的話，終端機提示符前面會出現 `(.venv)`。

## 套件

```bash
pip install fastapi uvicorn           # 安裝
pip install pytest httpx              # 測試用
pip freeze > requirements.txt         # 匯出（部署前要做）
pip install -r requirements.txt       # 從檔案安裝
```

## 啟動伺服器

```bash
uvicorn main:app --reload             # 開發用，存檔自動重啟
uvicorn main:app --host 0.0.0.0       # 讓同網段的人連得到
```

`main` = 檔名（`main.py`），`app` = 檔案裡的變數名。

## Git

```bash
git status                            # 不確定狀態時就打它
git add .                             # 全部加入暫存區
git commit -m "說明"                  # 存檔
git push                              # 推上 GitHub
git pull                              # 拉下更新
git log --oneline                     # 看歷史

git switch -c 分支名                   # 開分支並跳過去
git switch main                       # 跳回主線
git merge 分支名                       # 合併
git branch -d 分支名                   # 刪分支
```

## 測試

```bash
pytest                                # 跑全部
pytest -v                             # 顯示每個測試的名字
pytest test_main.py::test_login_success   # 只跑一個
```

## 查 IP（讓同學連你的網站）

```bash
ipconfig getifaddr en0                # macOS
ipconfig                              # Windows，找 IPv4 位址
```

## curl 測 API

```bash
# GET
curl http://127.0.0.1:8000/api/hello

# POST 送 JSON
curl -X POST http://127.0.0.1:8000/api/login \
  -H "Content-Type: application/json" \
  -d '{"username":"jase","password":"1234"}'

# 帶 token
curl http://127.0.0.1:8000/api/me \
  -H "Authorization: Bearer 你的token"
```

## 常用網址

| 網址 | 是什麼 |
| --- | --- |
| `http://127.0.0.1:8000` | 你的後端 |
| `http://127.0.0.1:8000/docs` | **自動產生的 API 文件，可以直接測試** |
| `http://127.0.0.1:5500` | Live Server 開的前端 |

## 停止伺服器

`Ctrl + C`（Mac 也是 Ctrl，不是 Cmd）
