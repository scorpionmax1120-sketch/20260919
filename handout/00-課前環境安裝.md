# 課前環境安裝

**請在上課前完成。** 課堂上不會有時間等大家安裝。

## 要裝的四樣東西

| 軟體 | 用途 | 下載 |
| --- | --- | --- |
| Python 3.10 以上 | 寫後端 | python.org/downloads |
| Visual Studio Code | 寫程式 | code.visualstudio.com |
| Git | 版本控制 | git-scm.com |
| Chrome 或 Edge | 要用 DevTools | 通常已經有了 |

另外請準備一個 **GitHub 帳號**（github.com 免費註冊）。

---

## Windows 安裝注意事項

### Python

下載安裝時，**第一個畫面最下面的 `Add Python to PATH` 一定要勾**。
忘記勾的話，終端機會找不到 `python`，最簡單的解法是重跑安裝程式選 Modify。

安裝完成後，開啟 **PowerShell** 測試：

```powershell
python --version
pip --version
```

### 如果 PowerShell 不給你啟動虛擬環境

看到 `因為這個系統上已停用指令碼執行` 的話，用系統管理員身分開 PowerShell 執行一次：

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

## macOS 安裝注意事項

系統內建的 Python 版本可能太舊。建議用 Homebrew：

```bash
brew install python git
```

測試：

```bash
python3 --version
pip3 --version
```

> macOS 上指令是 `python3` 和 `pip3`，不是 `python` 和 `pip`。

## 設定 Git 的身分（只要做一次）

```bash
git config --global user.name "你的名字"
git config --global user.email "你GitHub註冊的email"
git config --global init.defaultBranch main
```

email 建議用 GitHub 註冊的那個，否則 GitHub 不會把 commit 算在你的貢獻紀錄上。

## 最後檢查

開啟終端機（Windows 用 PowerShell、macOS 用 Terminal），逐行貼上：

```bash
python3 --version     # Windows 用 python --version
pip3 --version        # Windows 用 pip --version
git --version
code --version
```

**四行都要有版本號跑出來。** 有任何一行報錯，請在上課前告訴助教。
