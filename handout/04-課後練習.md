# 課後練習

從上到下難度遞增。**擇一完成就有收穫，全部做完你就有一個像樣的作品集專案。**

建議把課堂做的 MiniProfile **繼續長大**，不要每次都開新專案。
一個專案做到第五題，勝過五個半成品。

---

## 1 · 換成真的資料庫 ★

把 `USERS` 這個假資料 dict 換成 SQLite。

- 參考 [`../demo/step-8-sqlite/`](../demo/step-8-sqlite/)
- 驗收：API 規格和前端程式碼**一行都不用改**

---

## 2 · 補滿測試 ★

把測試補到 **15 個情境以上**。

- 參考 [`../prompts/06-產生測試.md`](../prompts/06-產生測試.md)
- 至少要有兩個是**資安測試**（不洩漏帳號是否存在、回應不含密碼）
- 驗收：`pytest -v` 全綠

---

## 3 · 加上註冊功能 ★★

新增 `POST /api/register`。

- 帳號重複要回 409
- 密碼長度至少 6 碼，太短回 400
- **密碼必須雜湊後才存**（用 `bcrypt` 或 `hashlib` + salt）
- 驗收：資料庫裡看不到任何明文密碼

---

## 4 · 讓個人資料可以編輯 ★★

新增 `POST /api/profile`，讓登入者修改自己的 `dept`。

- 參考 [`../prompts/07-練習-自己加一支-api.md`](../prompts/07-練習-自己加一支-api.md)
- **陷阱**：username 只能從 token 推導，絕對不能從請求 body 拿
- 驗收：用 A 的 token 無法修改 B 的資料

---

## 5 · token 加上過期時間 ★★★

把自製 token 換成 **JWT**，設定 30 分鐘過期。

- 過期的 token 要回 401
- 密鑰要從環境變數讀，不能寫在程式碼裡
- 驗收：把過期時間改成 10 秒，等 11 秒後再打 `/api/me`，應該被擋

---

## 6 · 部署上線並寫一份 README ★★★

把成品部署到 **Render**，讓任何人用網址打得開。
完整步驟與可部署的程式碼見 [`../demo/step-9-deploy/`](../demo/step-9-deploy/)。

先做兩件事，否則上線後前端會連不到 API：

1. 讓後端供應前端：`app.mount("/", StaticFiles(directory="web", html=True))`（放在所有 API 之後）
2. 前端的 API 位址改成自動判斷：`const API = location.port === "5500" ? "http://127.0.0.1:8000" : "";`

上線後逐項檢查：

- [ ] 用**手機的行動網路**打開（不要用同一個 Wi-Fi）
- [ ] 網址列有鎖頭
- [ ] 登入流程完整走一次（正確與錯誤帳密都試）
- [ ] 直接打 `profile.html` 會被踢回登入頁
- [ ] GitHub 上沒有密碼、金鑰、`.env`、`.db`
- [ ] `allow_origins` 沒有留著 `"*"`

README 要寫：這是什麼、怎麼在本機跑起來、用了哪些技術、線上網址。

## 接下來學什麼

| 順序 | 主題 | 為什麼是現在 |
| --- | --- | --- |
| 1 | 資料庫與 SQL | 今天用 dict 假裝的那塊，是真實系統的核心 |
| 2 | 密碼雜湊與 JWT | 今天的 token 是簡化版，正式專案不能這樣寫 |
| 3 | 前端框架（React / Vue） | 原生 JS 夠用，但畫面一複雜就會想要它 |
